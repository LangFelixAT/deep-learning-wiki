# Score-Based Generative Models

## Metadata
- Type: concept
- Status: developing

## Short definition
Generative models that learn score functions and sample using score-based dynamics.

## Intuition
Instead of learning a normalized probability density, [[2019 Generative Modeling by Estimating Gradients of the Data Distribution]] learns the direction in which log density increases.

Samples are generated by starting from noise and using stochastic dynamics guided by the learned score field.

## Mathematical formulation
- Related math: [[Score Matching]], [[Langevin Dynamics]], [[Annealed Langevin Dynamics]]
- Score: $\nabla_x \log p(x)$.
- Learned score network: $s_{\theta}(x) \approx \nabla_x \log p_{\mathrm{data}}(x)$.
- NCSN variant: $s_{\theta}(x, \sigma) \approx \nabla_x \log q_\sigma(x)$.

## Historical development
The 2019 Song and Ermon paper introduces a score-based generative modeling framework using NCSNs and annealed Langevin dynamics.
