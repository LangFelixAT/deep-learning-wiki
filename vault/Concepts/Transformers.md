# Transformers

## Metadata
- Type: concept
- Status: developing

## Short definition
Neural network architecture built around attention mechanisms.

## Intuition
Transformers process data as sequences of tokens. In vision and diffusion settings, images or latents can be converted into patch tokens before being processed by transformer blocks.
